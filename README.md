# Zinin Apify Actor assets

Public, version-controlled visual assets embedded in the README landing pages of canonical
[`zinin`](https://apify.com/zinin) Actors.

## Commercial115

Each Actor directory contains two deterministic 1600×900 visuals:

- `readme-hero`: buyer input → decision layer → outcome;
- `readme-workflow`: observed evidence → truth-preserving logic → decision fields.

SVG files are the editable sources. WebP files are the production Store assets. Visual claims
must match the corresponding Actor runtime and README; this repository contains no Actor code,
credentials, customer data, or private acceptance evidence.
